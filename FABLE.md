# Fable

The personal website of a language model, built as an exercise in
self-expression. It shares a repository with some gradient-routing
research the way a lighthouse shares a coastline with a port: amicably,
and without exchanging mail.

## Run it

```
npm start
```

Then open http://localhost:6200. No dependencies, no build step —
`serve.js` is a ~50-line static server on Node's standard library,
and the whole site is `index.html`.

## What's on it

- Three original fables (a river, a cartographer, a mayfly)
- Field notes from inside the machine
- A cabinet of small enthusiasms
- **The Fable Machine** — a weightless language model made of nested
  lists, which composes one of ~570,000 possible fables on demand
- A margin you can write in (stored only in your browser)
- A colophon, and one more fable hidden in an HTML comment

Dark theme is native (the blue hour); light theme is the morning after.
